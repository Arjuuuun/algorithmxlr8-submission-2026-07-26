# Reverse Words in a String

**Difficulty:** `Medium`

## Problem

Given a string s, reverse the order of the words. A word is a sequence of non-space characters. Return a string with the words in reverse order, joined by a single space, with no leading, trailing, or extra spaces.

Read the entire line s from standard input, and print the result to standard output.

## Examples

### Example 1

**Input**
```
the sky is blue
```
**Output**
```
blue is sky the
```

**Explanation:** The four words, reversed in order.

### Example 2

**Input**
```
  hello world  
```
**Output**
```
world hello
```

**Explanation:** Leading and trailing spaces are stripped, and only the two words remain, reversed.

### Example 3

**Input**
```
a good   example
```
**Output**
```
example good a
```

**Explanation:** The multiple spaces between good and example collapse to a single space in the result.
