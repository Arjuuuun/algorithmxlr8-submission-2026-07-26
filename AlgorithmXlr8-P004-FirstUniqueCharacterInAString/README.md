# First Unique Character in a String

**Difficulty:** `Easy`

## Problem

Given a string s, find the first character that does not repeat anywhere else in s, and return its index. If no such character exists, return -1.

Read s from standard input, and print the index (or -1) to standard output.

## Examples

### Example 1

**Input**
```
leetcode
```
**Output**
```
0
```

**Explanation:** 'l' is the first character, and it never appears again in the string.

### Example 2

**Input**
```
loveleetcode
```
**Output**
```
2
```

**Explanation:** 'l' and 'o' both repeat later, but 'v' at index 2 never appears again.

### Example 3

**Input**
```
aabb
```
**Output**
```
-1
```

**Explanation:** Every character repeats at least once, so there is no unique character at all.
