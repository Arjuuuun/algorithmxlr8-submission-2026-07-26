# Valid Anagram

**Difficulty:** `Easy`

## Problem

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

An anagram is formed by rearranging the letters of one word to produce a different word, using every original letter exactly once.

Read s on the first line and t on the second line of standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
anagram
nagaram
```
**Output**
```
true
```

**Explanation:** Both strings contain exactly the same letters, just rearranged.

### Example 2

**Input**
```
rat
car
```
**Output**
```
false
```

**Explanation:** The letters don't match up (car has a 'c' that rat doesn't have), so it is not an anagram.
