# Roman to Integer

**Difficulty:** `Easy`

## Problem

Roman numerals are represented by seven symbols: I (1), V (5), X (10), L (50), C (100), D (500), and M (1000). Usually symbols are combined largest to smallest, but a smaller symbol placed before a larger one means subtraction (for example, IV is 4, not 6).

Given a Roman numeral s, convert it to an integer.

Read s from standard input, and print its integer value to standard output.

## Examples

### Example 1

**Input**
```
III
```
**Output**
```
3
```

**Explanation:** Three I's in a row: 1 + 1 + 1 = 3.

### Example 2

**Input**
```
LVIII
```
**Output**
```
58
```

**Explanation:** L = 50, V = 5, III = 3, added together: 58.

### Example 3

**Input**
```
MCMXCIV
```
**Output**
```
1994
```

**Explanation:** M = 1000, CM = 900 (subtractive), XC = 90 (subtractive), IV = 4 (subtractive): 1994.
