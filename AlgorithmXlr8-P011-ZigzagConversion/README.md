# Zigzag Conversion

**Difficulty:** `Medium`

## Problem

A string s is written in a zigzag pattern across a given number of rows, moving down one row at a time until the bottom row is reached, then moving diagonally up until the top row is reached, and repeating.

Given a string s and an integer numRows, return the string formed by reading each row of the zigzag pattern from left to right, top row first.

Read s on the first line and numRows on the second line of standard input, and print the converted string to standard output.

## Examples

### Example 1

**Input**
```
PAYPALISHIRING
3
```
**Output**
```
PAHNAPLSIIGYIR
```

**Explanation:** Written zigzag across 3 rows and read row by row gives PAHNAPLSIIGYIR.

### Example 2

**Input**
```
PAYPALISHIRING
4
```
**Output**
```
PINALSIGYAHRPI
```

**Explanation:** The same string across 4 rows produces a different zigzag pattern, PINALSIGYAHRPI.

### Example 3

**Input**
```
A
1
```
**Output**
```
A
```

**Explanation:** With only 1 row, there is no zigzag at all; the string is unchanged.
