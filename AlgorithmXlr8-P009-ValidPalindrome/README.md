# Valid Palindrome

**Difficulty:** `Easy`

## Problem

A phrase is a palindrome if, after converting all uppercase letters to lowercase and removing all non-alphanumeric characters, it reads the same forward and backward.

Given a string s, return true if it is a palindrome, or false otherwise.

Read the entire line s from standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
A man, a plan, a canal: Panama
```
**Output**
```
true
```

**Explanation:** After cleaning, it becomes amanaplanacanalpanama, which reads the same both ways.

### Example 2

**Input**
```
race a car
```
**Output**
```
false
```

**Explanation:** After cleaning, it becomes raceacar, which is not the same reversed.
