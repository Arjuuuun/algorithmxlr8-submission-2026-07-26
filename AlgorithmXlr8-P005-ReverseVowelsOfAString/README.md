# Reverse Vowels of a String

**Difficulty:** `Easy`

## Problem

Given a string s, reverse only the vowels in the string (a, e, i, o, u, in either case), leaving every other character in its original position, and return the result.

Read the entire line s from standard input, and print the resulting string to standard output.

## Examples

### Example 1

**Input**
```
hello
```
**Output**
```
holle
```

**Explanation:** The vowels e and o swap positions, giving holle.

### Example 2

**Input**
```
leetcode
```
**Output**
```
leotcede
```

**Explanation:** The vowels e, e, o, e get reversed among themselves (to e, o, e, e), giving leotcede.
